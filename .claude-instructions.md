## Code Organization Rules
**CRITICAL: Keep files under 300 lines maximum**

If code exceeds 300 lines, split into separate files:
- UI components → separate from business logic
- Backend/API routes → separate from core logic
- Utils/helpers → separate modules
- Suggest proper file structure when splitting

Example split:
❌ BAD: app.py (450 lines - everything mixed)
✅ GOOD:
├── app.py (FastAPI routes - 150 lines)
├── agents/
│   └── processor.py (business logic - 180 lines)
└── utils/
    └── helpers.py (utility functions - 120 lines)
